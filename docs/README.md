## 🚀 Quick Start

1. **New Project?** Start with the [Master Guide](./master-guide.md)
2. **Choose a template** from the [Template Selection Guide](./templates/template-selection-guide.md)
3. **Fill it out** and submit to Claude
4. **Execute** the generated commands
