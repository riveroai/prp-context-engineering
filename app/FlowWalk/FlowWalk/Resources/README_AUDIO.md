# Audio Resource Required

## meditation_432hz.mp3

This app requires a 432Hz meditation audio file to be placed in this Resources folder.

### Requirements:
- Filename: `meditation_432hz.mp3`
- Duration: 30 minutes (or longer for looping)
- Frequency: 432Hz tuning
- Format: MP3
- Quality: 128-192 kbps (balance between quality and file size)

### Setup:
1. Add the audio file to this Resources folder
2. In Xcode, drag the file into the project navigator
3. Ensure "Copy items if needed" is checked
4. Add to target: FlowWalk

### Licensing:
Ensure you have the proper rights to use any audio file in your app.

### Recommended Sources:
- Create your own using audio software tuned to 432Hz
- Use royalty-free meditation music
- Commission custom audio from a composer
